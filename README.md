# 小度智能屏豆包语音技能（免刷机版）

通过开发者桥接模式为小度智能屏新增自定义技能，无需刷机，不破坏系统完整性，完全保留小度原有的所有功能。

## ✨ 核心功能
- **语音唤醒豆包**：对屏幕说“小度小度，打开豆包”，即可直接进入豆包进行流畅的语音通话聊天。
- **语音随时退出**：对屏幕说“小度小度，退出豆包”，即可关闭豆包并返回小度原桌面。
- **安全无损**：非刷机方案，基于开发者调试桥接实现，不影响设备原有的闹钟、影音、智能家居控制等功能。

## 🛠️ 安装与激活流程
1. **下载工具**：在电脑端下载【智能屏桥接软件】。
2. **连接设备**：使用 **Micro-USB 数据线** 将电脑与小度智能屏连接。
3. **版本检测**：运行桥接软件，自动检测设备当前的固件版本是否支持适配。
4. **获取激活码**：确认适配后，复制软件显示的**机器码**并发送给开发者，获取专属**激活码**。
5. **一键激活**：在桥接软件中输入激活码，完成技能安装与激活。
